# avatar-corporal

Resolução de imagem de composição corporal a partir de % de gordura + região dominante.
Só renderiza (seleciona imagem + descreve heatmap) — **não calcula % de gordura**.

Consumo via `git+ssh` (ver tag). API: `resolveBodyImage(input) -> { baseImageUrl, heatmap }`.

Status: em construção — ver Issues.
